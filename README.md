## `> whoami`
 
I'm a second-year BSCS student in the Philippines. I build learning tools that my classmates actually use, and I'm working on AI and security fundamentals from the ground up. Long term, I want to build a cybersecurity company.
 
## Now
 
- **Building:** Nurture (Nurture.ed), a learning platform with classroom quiz tools
- **Learning:** Rust, Python, Electron, Tauri
- **Researching:** a neural network from scratch, with hand-derived gradients and no autograd
- **Practicing:** CTFs and pentesting fundamentals, with binary exploitation on pwn.college next
  
## Projects
 
### Nurture
A set of learning tools, in use by my classmates.
 
- **Nurture.LEARN:** learning platform
- **Nurture.QUIZ:** real-time classroom quiz tool
- **QuizForge:** quiz builder
- Earlier: BaseBlitz and NumFlip (number-system quiz tools) and an Algorithm Problem Trainer
- Auth built on Supabase

### Character // Dossier
An Electron desktop app for self-improvement tracking, with multi-version profiles and a compare view.
 
### Other work
 
- Password Checker / Generator (C# WinForms)
- Guess the Word (C# WinForms)
- Static sites for local businesses (freelance)
